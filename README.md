# 🌸 SpeakWise AI

An AI-powered English Communication Coach that helps users improve their English speaking, grammar, and communication skills through interactive AI conversations.

## ✨ Features

- AI-based English conversation practice
- Grammar correction and sentence improvement
- Natural language feedback
- User Signup/Login authentication
- Chat history storage
- Interactive chat interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **AI Model:** Llama (via Groq API)
- **Authentication:** Flask Session & Password Hashing
- **Environment Management:** python-dotenv

## ⚙️ Installation

1. Clone the repository
2. Create a virtual environment
3. Install required dependencies
4. Add API key in `.env` file
5. Run the Flask application
